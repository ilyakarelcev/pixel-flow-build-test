# Фильтр мата для чата (Doodle Obby)

Локальный клиентский фильтр мата (русский + английский) для чата детской игры
«Обби онлайн с Друзьями» (Unity WebGL, Яндекс Игры, 6+). Эта папка — JS-прототип
и тестовый стенд; после обкатки логика переносится в C# для Unity.

## Быстрый старт

Открой `index.html` в браузере (работает с диска, сервер не нужен) — там живая
проверка, мини-чат и автотесты. Прогнать тесты из консоли: `node run-tests.js`
(сводка в stdout, детали провалов — в `test-output.txt`).

## Как устроено

Подход: **нормализация строки + поиск по корням** (не список целых слов и не
регулярки). Независимые языковые проходы, у каждого свои данные:
**русский и английский — основные** (подробные словари, транслит, leet),
немецкий, испанский, турецкий и японский — базовые наборы из самых ходовых
слов. Проходы не влияют друг на друга: добавление языка не меняет поведение
русского/английского, у каждого свой словарь, таблица замен и whitelist.

Нормализация (одинаковая для сообщения, корней и whitelist):

1. Нижний регистр.
2. Выброс всех «незначимых» символов: пробелы, точки, дефисы, эмодзи и т.п.
   Это ломает обходы вида `б л я д ь`, `б.л.я.д.ь`, `ху*й`.
3. Замена транслит-диграфов: `ya`→я, `sh`→ш, `kh`→х, `uy`→уи…
4. Замена одиночных символов-двойников: латиница→кириллица (`a`→а, `y`→у),
   цифры (`0`→о, `3`→з, `6`→б, `1`→i), символы (`@`→а, `$`→s), упрощение
   кириллицы (`ё`→е, `ы`→и, `й`→и, `ъ`/`ь` выбрасываются).
5. Схлопывание повторов: `бляяяядь`→`блядь`.

Дальше каждый корень (`пизд`, `бля`, `fuck`…) ищется как **подстрока**
нормализованного текста. Ложные срабатывания гасятся whitelist'ом: совпадение
отбрасывается, если его начало попадает внутрь вхождения обычного слова
(«застр**ахуй**», «кома**нда**», «бар**сук**», «не **бу**ду»).

Каждый нормализованный символ помнит диапазон исходных индексов, поэтому
`censor()` ставит `***` точно по месту мата в исходной строке.

## Файлы

| Файл | Что это |
|---|---|
| `js/filter.js` | Вся логика. Без DOM, без регулярок, без зависимостей. |
| `js/data-ru.js` | Данные русского прохода: алфавит, диграфы, таблица замен, корни, whitelist. |
| `js/data-en.js` | То же для английского. |
| `js/data-de.js`, `js/data-es.js`, `js/data-tr.js`, `js/data-ja.js` | Базовые наборы: немецкий, испанский, турецкий, японский. В японском вместо `alphabet` — `alphabetRanges` (диапазоны кодов хираганы/катаканы/кандзи). |
| `js/tests.js` | Тест-кейсы (мат, обходы, транслит, чистые фразы) + раннер. |
| `js/app.js` | Только UI стенда. |
| `run-tests.js` | Node-раннер тестов для консоли. |
| `research/` | Скачанные исходники словарей (gist-антимат, LDNOOBW) — справочно. |

## Как пополнять словарь

Всё в `js/data-ru.js` / `js/data-en.js`, код трогать не нужно:

- **Пропустили мат** → добавь корень в `roots`. Добавляй корень/основу
  («пизд», а не «пиздец»), без вариантов написания — обходы снимает
  нормализация. Чем короче корень, тем больше ложных срабатываний — проверь
  стендом, не ловит ли он обычные слова.
- **Ложное срабатывание** → добавь слово в `whitelist`. Достаточно основы без
  окончания: «барсук» покрывает «барсука/барсуки», потому что глушится любое
  совпадение, *начинающееся внутри* whitelist-слова.
- После правки прогони автотесты на стенде (или `node run-tests.js`) и добавь
  новый кейс в `js/tests.js`.

## Unity-ассет (готов)

Папка `unity/ProfanityFilter/` — drop-in ассет: C#-порт ядра (1:1 с
`filter.js`, без regex и UnityEngine-зависимостей в ядре), обёртка
`ChatProfanityFilter.Censor(...)`, словари в `Resources/ProfanityFilter/*.txt`
и EditMode-тесты. Инструкция — `unity/ProfanityFilter/README.md`.

Поддержка синхронности стенда и ассета:

- **Источник правды — JS-словари стенда** (`js/data-*.js`). После их правки
  выполните `node export-unity-data.js`: перегенерирует `.txt` словари ассета
  и C#-файл тест-кейсов из `tests.js` + `stress-corpus.js`.
- **Проверка C#-порта без Unity**: `unity-dev/build-and-test.cmd` — собирает
  ядро системным csc и гоняет весь корпус (тот же, что на стенде).
- **Кнопка «⬇ Ассет для Unity» в шапке стенда** отдаёт
  `ProfanityFilter-Unity.zip`. После правки словарей/кода ассета пересоберите
  архив: `Compress-Archive -Path unity\ProfanityFilter -DestinationPath ProfanityFilter-Unity.zip -Force`
  (PowerShell, из папки `chat-filter`).

## Производительность

Замер встроен в `node run-tests.js` (полный корпус ~480 сообщений × 200
повторов, все 6 языков): **~16 мкс на сообщение** на десктопе, то есть
~0.016 мс. Даже с запасом ×20 на слабый телефон + WebGL это ~0.3 мс на
сообщение — при чате в несколько сообщений в секунду фильтр не виден в
профайлере вообще. Алгоритм линейный: O(длина сообщения × число корней),
без регулярок и аллокаций в горячем цикле; добавление языка стоит ровно
его число корней (немецкий+испанский+турецкий+японский ≈ +35 корней к ~130).

## Известные ограничения (осознанные компромиссы)

- Из-за выброса пробелов возможны ложные срабатывания на стыках слов
  («спи здесь» → «пизд»). Политика — лучше перефильтровать; частые случаи
  гасим whitelist'ом по мере находок.
- Из-за схлопывания повторов и whitelist-стыков отдельные хитрые написания
  («не ебал» слипается в whitelist-слово «небал») могут проскочить. Критерий
  приёмки — тривиальные обходы модератора, а не криптография.
- Жёсткие оскорбления без мата («дебил», «лох») сейчас не фильтруются —
  добавляются одной строкой в `roots`, если решим.
