Инструкция Редактора

🎨 Зоны (Рисование)

Выберите Зону в левой панели и ведите по полю левой кнопкой мыши. Правая кнопка мыши — ластик (стирает зоны).

Свойства: У каждой зоны свой ID (zone_1, zone_2) и базовый номинал спавна.

📦 Объекты (Drag & Drop)

Просто перетащите объект из палитры на поле. Чтобы скопировать уже установленный объект, перетаскивайте его с зажатой клавишей Alt.

🎯 Миссии (Цели уровня)

Важно: Чтобы добавить миссию, зажмите объект в палитре и перетащите его в блок «Миссии» наверху. Он автоматически превратится в цель (например, «Собрать блоки» или «Разбить ящики»).

⚡ Активации

Вы можете сделать так, чтобы разрушение объекта включало новую зону спавна. Выберите объект на поле и в панели Свойства выберите ID зоны для активации.

🚀 Публикация

Сохраните проект в облако, а затем нажмите Опубликовать, чтобы ваш уровень появился в общем списке в основной игре!
