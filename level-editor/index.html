Инструкция редактора

keyboard Горячие клавиши

  • B — Кисть (Brush)
  • M — Выделение (Select)
  • I — Пипетка (Picker)
  • Del — Удалить выбранное
  • 1 - 9 — Быстрый выбор цвета из палитры

brush Рисование

  • Alt + ЛКМ — Стирание блоков (или ПКМ)
  • Ctrl + ЛКМ — Быстро взять цвет с холста
  • Symmetry — Режим зеркального рисования (H/V)

select_all Выделение

  • Shift + Тянуть — Добавить к выделению
  • Alt + Тянуть — Убрать из выделения
  • COPY — Нажмите, затем тяните выделение для копирования

category Юниты (Склад)

  • Drag & Drop — Свободное перемещение между колонками
  • Link Mode — Тяните линию между юнитами для связи
  • Equalize — Балансировка патронов под HP блоков
